How to play

  1. Press Start Game to begin.
  2. Drag the raised verb tiles onto one another to swap them into the correct person and number: Singular, Dual, or Plural.
  3. Select a person button to check that row, or Check All to check the whole table.
  4. Choose a lakaara to practice a specific tense or mood.
  5. Start with 100 points. Each new wrong form in a checked cell costs 2 points. Rechecking it costs nothing. Correct forms turn green.
  6. Select New Game for another puzzle.
