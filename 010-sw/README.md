# Sanskrit Zodiac Wheel

Spin the wheel to randomly reveal a zodiac sign in Sanskrit. A sign can appear
again on a later spin. Each result appears below the wheel in Devanagari and
transliteration, for example:
`वृश्चिकः - vRRishchikaH`.

You can spin again as soon as the wheel stops. The wheel, button, and result
stay centered and resize to fit smaller screens.

## Files

- `index.html` contains the wheel interface and shared theme integration.
- `script.js` selects and displays a zodiac sign for each spin.
- `styles.css` contains the wheel layout and responsive styles.
- `wheel.png` and `marker.png` are the wheel and pointer images.
- `../shared/game-theme.css` provides the shared page shell, button, and result
  message styles.
- `../js/navbar-loader.js` loads the shared site navigation.
