How to play

  1. Press Start Game to begin.
  2. Drag the raised noun tiles onto one another to swap them into the correct case and number: Singular, Dual, or Plural.
  3. Select a case button to check that row, or Check All to check the whole table.
  4. Use the gender selector to choose a noun or pronoun group.
  5. Each new misplaced form in a checked cell costs 2 points. Correct forms turn green.
  6. Select New Game for another puzzle.
